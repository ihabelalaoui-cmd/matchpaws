# Match’Paws V1

Prototype web front-end prêt pour GitHub Pages.

## Ce qui fonctionne
- landing page responsive
- création d’un profil animal
- sélection du service
- date et zone
- matching de démonstration
- explication « Pourquoi ce match ? »
- profil intervenant
- demande de réservation simulée
- mémorisation locale avec `localStorage`
- aucune collecte ou transmission de données vers un serveur

## Limites V1
Il n’y a pas encore de vraie base de données, authentification, paiement, messagerie, vérification d’identité ou publication serveur.

## Déploiement
Le site est conçu pour être publié directement via GitHub Pages depuis la branche `main` et le dossier racine.

Pour un vrai lancement commercial, les comptes, paiements, données personnelles, vérifications, assurance, conditions contractuelles et obligations réglementaires doivent être gérés avec un adulte et des professionnels compétents.
